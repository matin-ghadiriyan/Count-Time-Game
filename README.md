# Count Time Game ⏱️

بازی چندنفره‌ی زمان‌بندی تحت وب؛ هر بازیکن تلاش می‌کند بدون دیدن تایمر، زمان مشخصی را دقیق‌تر از بقیه متوقف کند.

## ✨ امکانات

- بازی آنلاین چندنفره با **Flask-SocketIO** (همه چیز Real-Time)
- اتاق‌های خصوصی با **کد اتاق** یکتا
- زمان‌سنجی **معتبر سمت سرور** با `time.perf_counter()` (ضد تقلب)
- احراز هویت کاربران با **Flask-Login** (ثبت‌نام / ورود)
- ذخیره‌ی بازی‌ها و نتایج در **SQLite**
- صفحه‌ی **داشبورد**، **جدول رده‌بندی** و **تاریخچه‌ی بازی‌ها**
- رابط کاربری مدرن، تاریک، واکنش‌گرا و **راست‌به‌چپ (فارسی)**

## 🧱 پشته‌ی فناوری

| لایه | فناوری |
|------|--------|
| Backend | Python 3.10+, Flask |
| Real-Time | Flask-SocketIO |
| Database | SQLite + Flask-SQLAlchemy |
| Auth | Flask-Login, Werkzeug |
| Frontend | HTML5, CSS3, Vanilla JS, Socket.IO |

## ⚙️ نصب و اجرا

1. **ساخت محیط مجازی**

   ```bash
   python -m venv .venv
   ```

   فعال‌سازی در ویندوز:

   ```bash
   .venv\Scripts\activate
   ```

2. **نصب وابستگی‌ها**

   ```bash
   pip install -r requirements.txt
   ```

3. **تنظیمات محیطی**

   فایل `.env` را باز کنید و مقادیر را بررسی کنید. به‌صورت پیش‌فرض از SQLite استفاده می‌شود:

   ```env
   DATABASE_URL=sqlite:///count_time_game.db
   ```

4. **اجرای برنامه**

   ```bash
   python run.py
   ```

5. مرورگر را باز کنید: [http://localhost:5000](http://localhost:5000)

## 🎮 نحوه‌ی بازی

1. ثبت‌نام کنید و وارد شوید.
2. از داشبورد یک **اتاق بسازید** و کد آن را برای دوستان بفرستید (یا با کد وارد اتاق شوید).
3. میزبان روی «شروع بازی» می‌زند تا بازی وارد فاز اجرا شود.
4. بازی **نوبتی** است: بازیکنان به‌ترتیب نوبت‌شان بازی می‌کنند.
5. بازیکنِ نوبت‌دار روی «شروع» می‌زند و شمارش از همان لحظه در سرور آغاز می‌شود.
6. **بازیکن نوبت‌دار زمان خودش را نمی‌بیند** و باید پس از زدن «توقف»، تعداد ثانیه‌های سپری‌شده را **حدس** بزند.
7. **حریفان می‌توانند زمان این بازیکن را زنده ببینند** (چون از آن‌ها مخفی نیست) تا بازی جذاب و رقابتی باشد.
8. وقتی نوبت هر بازیکن تمام شد (یعنی Stop زد و حدسش را ثبت کرد)، نوبت به بازیکن بعدی منتقل می‌شود تا همه‌ی نوبت‌ها کامل شود.
9. در پایان، **کسی که حدسش کمترین اختلاف را با زمان واقعی داشته باشد، برنده** است.
10. رتبه‌بندی نهایی به‌صورت **۱، ۲، ۳، ۴ و …** برای همه‌ی بازیکنان بر اساس میزان نزدیکی حدس نمایش داده می‌شود.
